## IDENTITÉ LÉGALE

| Champ | Valeur |
|-------|--------|
| Nom commercial | AK Réseaux & Bâtiment |
| Forme juridique | Micro-entreprise (auto-entrepreneur) |
| Activité principale | Travaux d'installation électrique, réseaux et systèmes techniques |
| Code NAF principal | **4321A** — Travaux d'installation électrique dans tous locaux |
| Type de prestation | Services artisanaux (prestations de service) |
| Seuil CA annuel | 77 700€ (plafond micro-entreprise services) |
| Taux cotisations sociales | 21,2% (avec ACRE : ~10,6% la 1ère année) |

### Pourquoi le code 4321A ?

Ce code couvre légalement :
- Installation électrique courant fort
- Installation systèmes d'alarme et contrôle d'accès
- Câblage réseaux courants faibles (data, fibre, téléphonie)
- Installation systèmes télécommunications dans les bâtiments
- Maintenance et dépannage des installations

Il couvre 80% de tes activités terrain avec un seul code.

## ÉTAPES D'IMMATRICULATION

### Étape 0 — AVANT TOUT (critique)
- [ ] **Appeler Pôle Emploi** → demander activation ACRE avant immatriculation
- [ ] Demander confirmation écrite du droit à l'ACRE
- [ ] Vérifier si tu peux conserver une partie de l'ARE (allocation) en parallèle du début d'activité

### Étape 1 — Immatriculation
- [ ] Aller sur **autoentrepreneur.urssaf.fr**
- [ ] Créer le compte et remplir le formulaire
- [ ] Déclarer : activité artisanale (BTP)
- [ ] Mentionner le code NAF 4321A
- [ ] Coût : **GRATUIT**
- [ ] Délai réception SIRET : 1 à 3 semaines

### Étape 2 — Stage CMA (Chambre des Métiers)
- [ ] Contacter la CMA de ta région
- [ ] Vérifier si tu peux être exempté grâce à ton expérience terrain
- [ ] Si non exempté : Stage Préalable à l'Installation (~194€) — à planifier dans le budget
- [ ] **ATTENTION** : obligatoire pour activité artisanale, ne pas sauter cette étape

### Étape 3 — Compte bancaire dédié
- [ ] Ouvrir un compte séparé **dédié exclusivement** à l'activité
- [ ] Options sans frais ou low-cost :
  - **Nickel Business** : 0€ ouverture, ~5€/mois
  - **Ma French Bank Pro** : option économique
  - **Shine** : 9€/mois, meilleur pour la gestion (recommandé à terme)
- [ ] Ne jamais mélanger perso et pro sur le même compte
- [ ] Obligatoire légalement au-delà de 10 000€/an de CA

### Étape 4 — Assurance (stratégie adaptée au budget 200€)

**Problème réel :** Les assurances BTP coûtent cher. Avec 200€, il faut séquencer intelligemment.

**Stratégie en 2 temps :**

**Mois 1-3 : Courants faibles uniquement (RC Pro seule)**
- Câblage réseau data, fibre optique, téléphonie
- Installation alarme et contrôle d'accès
- Assistance technique, conseil, coordination
- Services numériques (devis, BIM, documents)
- RC Pro seule suffit : ~200 à 350€/an → mensualiser à ~25€/mois

Assureurs RC Pro BTP accessibles :
- **Hiscox** (en ligne, devis rapide)
- **Simplis** (spécial artisans, mensuel possible)
- **AssurancesBTP.com**
- **Luko Pro**

**Mois 3-6 : Ajouter décennale pour travaux courant fort**
- Quand le CA commence à rentrer
- Décennale : ~500 à 900€/an pour auto-entrepreneur BTP
- Permet de facturer les travaux électricité courant fort (installation, mise aux normes)

**Résumé assurance Phase 1 :**
| Couverture | Coût mensuel | Activités couvertes |
|------------|--------------|---------------------|
| RC Pro seule | ~25€ | Télécom, réseau, alarme, conseil, digital |
| RC Pro + Décennale | ~75€ | Tout + électricité courant fort |

## OUTILS NUMÉRIQUES (budget zéro à minimal)

### Facturation & Compta
- [ ] **Freebe** (gratuit jusqu'à certain seuil) — ou **Henrri** (gratuit)
- [ ] Créer le premier modèle de facture avec logo
- [ ] Configurer les mentions légales obligatoires sur la facture :
  - Numéro SIRET
  - Numéro RCS ou RM (Chambre des métiers)
  - Assureur + numéro de police
  - Mention TVA non applicable (article 293B du CGI) si non assujetti

### Communication & Acquisition
- [ ] **LinkedIn Pro** : profil complet (gratuit) — priorité haute
- [ ] **Google Business Profile** : fiche locale (gratuit) — acquisition locale directe
- [ ] **Page Facebook Pro** : réseau AOF notamment (gratuit)
- [ ] **Email professionnel** : prenom@ak-reseaux-batiment.fr
  - Option gratuite : Gmail personnalisé via Google Workspace (6€/mois)
  - Option économique : OVH mail (1-2€/mois)

### Site Web (optionnel en phase 1)
- [ ] **Carrd.co** : site vitrine simple, 19€/an
- [ ] Contenu minimal : présentation, services, zone d'intervention, contact
- [ ] Peut attendre la phase 2 — LinkedIn suffit au départ

### Nom de domaine
- [ ] **ak-reseaux-batiment.fr** ou **akbtp.fr** — vérifier disponibilité
- [ ] OVH ou Namecheap : ~15€/an
